# Censo Vivo Ecuador

Portal experimental para explorar los resultados del VIII Censo de Población y VII de Vivienda 2022 del Ecuador. El proyecto está en la **fase 0: verificación de fuentes y entorno**. Aún no se publican mapas ni indicadores.

## Estado del trabajo

Cada fase se desarrolla en una rama y se presenta en un pull request antes de iniciar la siguiente. El [plan de trabajo](https://github.com/diegocevallos-tech/censo-vivo-ecuador/milestones) contiene las tareas y sus criterios de verificación.

## Fuentes y uso de datos

La fuente estadística prevista es el [INEC, Censo Ecuador 2022](https://www.censoecuador.gob.ec/data-censo-ecuador/). La cartografía se verifica por separado. Las cifras, geometrías y variables solo se incorporarán después de comprobar su procedencia, cobertura y posibilidad de uso. El código tiene licencia MIT; las condiciones aplicables a los datos se explican en [DATA_LICENSE.md](DATA_LICENSE.md).

Este repositorio público publicará únicamente **estadísticas agregadas**. No se distribuirán registros de personas ni hogares.

## Reproducibilidad

El entorno y el proceso de adquisición se incorporan durante esta fase. Ninguna cifra del censo se simulará para desarrollar el portal.
